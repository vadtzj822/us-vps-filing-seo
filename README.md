## 免备案不等于没人管：三条边界

第一条，机房所在地的法律照样管。美国机房受 DMCA 这类法规约束，做版权侵权、大规模垃圾邮件，机房会直接停机，按 AkkoCloud 的条款停机也不退款。

第二条，人在国内、业务面向国内用户，内容违法照样能追到运营者。域名注册商、支付通道、登录 IP 都会留下记录，"服务器在美国就查不到"是误解。

第三条，不备案不等于匿名。商家手里有注册邮箱、支付记录、登录 IP，IP 段归属也能查到机房。

免备案省掉的是审批流程，法律责任一样在。跨境电商独立站、外贸企业官网、海外推广落地页、个人博客、技术项目部署、AI API 中转，这些是免备案机器的正当用途。

## 常见问题

**免备案的机器会不会被墙？**
不会因为"免备案"被墙。能不能访问取决于 IP 和域名本身有没有被墙，跟备不备案没有直接关系。

**域名还要单独备案吗？**
不用。备案备的是"域名 + 国内服务器"这个组合，服务器在境外，域名解析过去就能用，DNS 放 Cloudflare 这类海外服务商也行。

**不备案会不会被百度降权？**
相对弱势，但不排斥。百度对已备案站点有收录倾斜，境外服务器不是惩罚项。靠百度吃饭的站，这一项要算进成本。

**AkkoCloud 能退款吗？**
不能。官方条款明确不支持退款，也不能以 IP 非原生为由退。这是它和"3 天无理由退款"类商家最大的差别，也是下单前最该想清楚的一点。
